1 · Collegamento al repository GitHub

La configurazione vive nel file config/app-config.json del tuo repository: l'app la scarica all'avvio. Serve un token GitHub con permesso Contents: Read and write solo su questo repository.

2 · Aspetto

Nome mostrato nell'app e colore principale (pulsanti, badge, barre di avanzamento).

3 · API agganciate

Ogni sorgente deve rispondere nel formato descritto in docs/API.md. Usa solo contenuti di cui hai i diritti.

4 · JSON della configurazione

Per vedere cosa verrà salvato, oppure per copiare la configurazione nell'admin nascosto dell'app (Importa).
